NJR Konwerter 1.0.5

Czyszczenie i organizacja zbiorów muzycznych oraz migracja bibliotek DJ pomiędzy systemami. Pełny eksport bez klucza licencji. Wersja 1.0.5 naprawia uruchamianie na Windows (starsze 1.0.2–1.0.4 mogły kończyć się błędem NumPy).

Do czego służy NJR Konwerter?

NJR Konwerter pomaga utrzymać bibliotekę DJ w porządku oraz przenieść ją między programami — bez ręcznego odtwarzania playlist, cue i tagów.

  • Czyszczenie i organizacja — martwe ścieżki, duble, orphaned tracks, porządkowanie folderów i playlist, naprawa ścieżek (m.in. Serato / VirtualDJ).
  • Migracja między systemami — VirtualDJ ↔ Serato ↔ Engine DJ ↔ Rekordbox (oraz eksporty DJXML i pokrewne), z zachowaniem struktury list i możliwie największej ilości metadanych.
  • Edycja bazy VirtualDJ — praca na lokalnej bazie: przeglądanie, poprawki, eksporty pod inne oprogramowanie.

Pracujesz głównie w jednym systemie? Użyj go do porządkowania. Zmieniasz setup albo grasz na kilku platformach? Użyj go jako mostu migracyjnego.

Mac — instalacja i pierwsze uruchomienie

Program nie jest z App Store — nie potrzebujesz konta Apple Developer. Przy pierwszym uruchomieniu macOS może odmówić startu i pokazać ostrzeżenie — to standardowe zachowanie dla aplikacji pobranych z internetu.

1. Wgraj program do Aplikacje

Otwórz pobrany plik .dmg. W oknie obrazu często jest tylko plik NJR-konwerter (bez skrótu do Aplikacji) — to w porządku.

  • Naciśnij Shift + Command + A, żeby otworzyć folder Aplikacje, i przeciągnij tam NJR-konwerter z okna DMG. Lub: zaznacz plik w DMG → Command + C → w Aplikacjach → Command + V.

Potem wysuń DMG (ikona dysku na pulpicie lub w Finderze → wysuń).

2. Zezwól na uruchomienie — Ustawienia systemowe

To jest główny sposób, który działa, gdy macOS blokuje program (np. komunikat z przyciskami „Kosz” i „Gotowe”):

  1. Raz spróbuj uruchomić NJR-konwerter z folderu Aplikacje (np. dwuklik). Gdy pojawi się blokada, zamknij okno (Gotowe).
  2. Otwórz Ustawienia systemowe (ikona koła zębatego w Docku lub menu Apple).
  3. Wejdź w Prywatność i bezpieczeństwo (lub sekcję Bezpieczeństwo, zależnie od wersji macOS).
  4. Przewiń w dół. Powinna być informacja, że NJR-konwerter został zablokowany — obok znajdziesz przycisk w stylu Otwórz mimo to / Otwórz i tak. Kliknij go i potwierdź.
  5. Uruchom ponownie NJR-konwerter z Aplikacje. Kolejne uruchomienia zwykle już nie wymagają tych kroków.

Jeśli przycisku nie widać, upewnij się, że najpierw była próba otwarcia programu — dopiero wtedy macOS dopisuje wpis w ustawieniach bezpieczeństwa.

Kopia zapasowa bazy

Zalecam pracę na kopii zapasowej bazy VirtualDJ (oraz powiązanych plików Serato / Engine / Rekordbox). Przed większymi zmianami lub eksportami zrób backup, żeby nie uszkodzić oryginalnych danych.

Windows — instalacja

Ważne: jeśli masz wersję 1.0.2, 1.0.3 lub 1.0.4 i program od razu się wyłącza z błędem numpy — pobierz 1.0.5 poniżej.

Uruchom pobrany plik .exe (nie wymaga instalatora — to portable onefile). Gdy pojawi się SmartScreen, wybierz Więcej informacji → Uruchom mimo to.

Jeśli Windows Defender lub inny antywirus zatrzyma plik, pozwól na uruchomienie albo dodaj wyjątek — pobieraj wyłącznie z tej strony lub z oficjalnego release na GitHubie.

Usterki i sugestie

Projekt jest open source i nadal się rozwija. Jeśli coś nie działa, napisz (formularz kontaktowy w sklepie lub e-mail): podaj system (Windows / Mac), co robiłeś kroku po kroku i ewentualnie załącz zrzut ekranu.
